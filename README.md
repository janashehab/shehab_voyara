# Voyara

AI travel planning and booking. Phase 1 is this Next.js website. The planner will recommend only team-approved catalog records.

The current tree is the Step 1 foundation: Next.js, TypeScript, Tailwind CSS, and ESLint. Database, auth, planning, booking, and provider sync are later steps.

- Agent instructions: [AGENTS.md](./AGENTS.md)
- Catalog and provider rules: [docs/architecture/data-policy.md](./docs/architecture/data-policy.md)

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
